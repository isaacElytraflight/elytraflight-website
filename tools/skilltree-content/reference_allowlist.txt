# Allowlist for tools/skilltree-content/reference_gate.py
#
# One exception per line: path, a tab, a JSON pointer (or * for the whole
# file), a tab, and the reason. Blank lines and lines starting with # are
# ignored. A hit is suppressed only when the file path ends with the path
# column and the pointer matches.
#
# Exact course selector labels. Pointer "=" is not a JSON path: the third
# column is the whole string. The gate waives the university-name and
# course-number patterns only when that string is a collections tab_title.
# The same words in a title, a question, or any other learner-facing field
# still fail. A professor, textbook, reader, week, or lecture still fails
# inside a selector label. A different tab_title, including "EECS 127", is
# not on this list.
#
# Format: <Topic course title> (<University> <Course number>), or (Generic)
# when there is no single source course.
*	=	Microelectronic Devices and Circuits (Berkeley EE 105)
*	=	Dynamic Systems and Feedback (Berkeley ME 132)
*	=	Feedback Systems (Generic)
*	=	Nonlinear Optimization (TU Graz)
#
# Pattern choices, so they do not need a per-hit exception:
# - Lecture slides are "the slides", "lecture slides", "slide deck", or "slide N".
#   A bare "slides" is the motion verb ("a mass slides", "the bias point slides").
# - "section" must not follow a hyphen, so "cross-section" is not a source section.
# - University "MIT" uses a word boundary, so "limit" does not match.
# - "textbook" and "the book" are banned in learner-facing sentences. The word
#   "book" alone is not, so "bookkeeping" is not a hit. A string that is exactly
#   "textbook" is the collections box kind, not a sentence, and the UI scan skips it.
#   A circuit "source" (current source, voltage source) is not a citation, so the
#   word "source" alone is not banned.
# - "chapter" and "section" are banned when followed by a number. The app's
#   own word "chapters", with no number, is the topic grouping, not a source
#   chapter title.

# Path exceptions (pointer other than "=") are for a real false positive.
# The "=" lines above are the course selector labels, not content exceptions.
